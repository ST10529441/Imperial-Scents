Project Overview:

Imperial Scents is a newly established fragrance business founded by Ofentse Lebenya on 29 July 2026. Operating as a sole proprietorship, the business sells affordable, high-quality fragrances to a broad audience including students, young professionals and adults. The company projects an average monthly profit and aims to build a strong digital presence through a professional e-commerce website.
The brand identity is built around regal elegance and accessibility. The official taglines are "POWER. PRESENCE. LEGACY." and "LONG LASTING IMPRESSIONS." The colour palette consists of Imperial Cream, Royal Crimson, Crown Gold, and Imperial Black - all derived from the brand logo featuring a crowned "IS" monogram.
This project (Part 1) covers the website proposal, design documentation and basic HTML structure. Parts 2 and 3 will follow in future submissions.

CSS Implementation:

- CSS was implemented after the initial HTML structure was completed.

- The stylesheet is used to control the visual design and layout of the website without changing the underlying HTML structure.
<br>
Main CSS Features:

- Typography: Playfair Display for headings and Inter for body text

- Colour scheme: Imperial Cream, Royal Crimson, Crown Gold and Imperial Black

- Box model: Margins, padding, borders and sizing

- Flexbox: Used for navigation, grids and product/card layouts

- Product cards: Consistent card styling, spacing and image areas

- Buttons: Styled navigation and "View in Store" buttons

- Hover effects: Interactive visual feedback for links, buttons and cards

- Responsive design: Media queries for different screen sizes

- Image handling: Product images use consistent sizing while maintaining their proportions

- Layout: Flexible content widths and responsive card arrangements
<br>
Responsive Design:

- The website uses CSS media queries to adjust the layout for different screen sizes.
<br>
Desktop

- The website displays multiple cards across the page and provides a wider content layout.
<br>
Tablet

- Cards adjust their width to fit smaller screens while maintaining the overall structure.
<br>
Mobile

- Cards change to a single-column layout, navigation links become vertically arranged and buttons expand to make them easier to use on smaller screens.
<br>
Responsive breakpoints currently include:

- 768px for tablets

- 480px for small mobile devices

- 360px for very small mobile devices

- 1400px for larger desktop screens
